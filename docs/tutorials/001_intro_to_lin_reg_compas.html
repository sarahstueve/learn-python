Intro to Linear Regression in Python

Modeling the Effect of Sex and Race on Risk of Violence using COMPAS score data

Author

Sarah Stueve

Modified

October 30, 2026

This tutorial is based on an R version of this tutorial, which can be found here

The data that we’ll be using for this tutorial is from this work by ProPublica which aimed to assess a popular commercial system COMPAS, which is a criminal defendant risk-assessment tool, for bias against any individual groups. They evaluated the Risk of Recidivism algorithm, in this tutorial, we’re going to evaluate the Risk of Violence algorithm.

Learning Objectives

  1. Gain familiarity with Python
  2. Practice reading and manipulating data in Pandas
  3. Run a linear model using statsmodels
  4. Visualize predicted risk of violence scores with error bars

Use this link to download the dataset (right-click on the link and select Save As...). Make sure to save it somewhere you’ll remember, like your Desktop or Downloads. We’ll be moving it somewhere else later.

Update the race and ethnicity labels

The names used to represent the races/ethnic groups are both messy and/or antiquated. We’ll create a new column in our dataframe called race_ethnicity to contain our new attributes, to make a few adjustments that will, at least, partially improve the labels.

To do this, we will use the pd.Series.replace method. In order to replace multiple values at the same time, we’ll use a base Python object called a dictionary. It’s very similar to how it sounds: in a physical dictionary, we can find words mapped to definitions, right? A dictionary in Python is similar. In the context of pd.Series.replace, we provide a Python dictionary with the current value we want to replace mapped to what we want to replace it with. The format is {<to replace>: <replacement>}. In the context of our data, this looks like:

{
    'Caucasian': 'White',
    'African-Am': 'African-American',
    'Oriental': 'Asian'
}

So, let’s apply that to creating a new column race_ethnicity, where the antiquated or messy terms are replaced:

compas_data['race_ethnicity'] = compas_data['Ethnic_Code_Text'].replace(
    to_replace = {'Caucasian': 'White',
                  'African-Am': 'African-American',
                  'Oriental': 'Asian'}
)
# let's look at the original labels vs the new labels

print()

Remove rows with “missing” score value

Let’s look at DecileScore, which represents the COMPAS score reported in deciles (i.e., increments of ten points). According to the Practitioners Guide to COMPAS, if a person scores a 4 on this scale, then 60% of the population looks more risky in that area than this person does, and 30% has been assessed as less risky. Typically a decile score of 1-4 is low (below average), 5-7 is moderate (average), and 8-10 is high (above average).

Creating the linear model

Now, on to modeling.

We know that we have a subset of data on “Risk of Violence” from the COMPAS dataset and we want to determine the effect of sex and race on the risk of violence scores.

We can do this using statsmodel’s OLS function with the .from_formula method, which will allow us to establish the relationships between variables of interest ourselves. This is similar to the lm function in R. sm.OLS will take care of one-hot encoding the data in order to make predictions.

We’ll then group the data by race and take the average of the predicted DecileScores to answer the question “what is the mean risk of violence score across all races?”

Fitting the model

First, we write out our formula (the ~ here can be read as “DecileScore as a function of race and sex”) and create the model. From there, we have to explicitly tell python to .fit() the model to the data, which provides the results. Then, we review the regression results by calling results.summary().

Remember that our race and ethnicity labels are Caucasian, African-American, Hispanic, Other, Asian, Native American, Arabic and the level African-American is the first level in the default alphabetical order. So every other level is displayed in relation to African-American people.

# fit model and get average predictions by race
formula = "DecileScore ~ race_ethnicity + Sex_Code_Text"
# initialize the model with the formula
model2 = sm.OLS.from_formula(formula = formula,
                            data = violence_risk)
# fit the model to our data
results = model2.fit()
# view the regression results in table format
results.summary()

Interpreting the results

Our Intercept is African-American (the default because it comes first in alphabetical order), meaning Black defendants are assigned on average a score for risk to re-offend of 5.33. Arabic defendants are assigned a score that is, on average, 1.49 lower than African-American, which results in 3.84, etc.

There are a few things we look for to validate the linear model:

  1. are the coefficients statistically significant?
  2. What do the F-statistic and R-squared tell us about statistical significance and the strength of the effect?
  3. Are the skew and kurtosis large?

For the first, all of our co-efficients are statistically significant except for the race_ethnicity binarized variable for Native American defendants.

For the second, the F-statistic indicates statistical significance (see Prob (F-statistic) = 0 below it) and is high. While sample size does inflate the F-statistic, the value of 380.1 indicates a moderate-strong correlation. The R-squared value indicates a moderate-strong correlation in the context of social science and modeling human behavior.

For the third, the kurtosis just above 3 indicates the presence of some outliers and the skewness indicates that those outliers are likely to be at the higher end of the distribution (skewed to the right).

Based on the above, we can believe the results we see in this model that race_ethnicity has a moderate-strong effect on risk of violence scores.

Investigating the model effect by race and ethnicity

Next, we want to understand the effect of the race and ethnicity, and sex on average Risk of Violence DecileScore predicted by the model.

To do this, we can first calculate the Estimated Marginal Means (EMMs) which are model-predicted average values for the response variable (in this case, Risk of Violence DecileScore) at each level of a factor or categorical variable (race_ethnicity), adjusted for other variables in the statistical model.

emm = emmeans(results, "race_ethnicity")

Using the EMMs, we can plot the average DecileScores for each race, along with the standard error associated with the estimate, to visualize differences between each group.

plot = (
    ggplot(emm.frame, aes(x = 'reorder(race_ethnicity, emmean, ascending = True)', y = 'emmean'))
    + geom_point(color = 'lightskyblue')
    + geom_errorbar(aes(ymin = 'lower_cl', ymax = 'upper_cl'),
                    width = 0.01, color = 'lightskyblue')
    + coord_flip()
    + theme_seaborn()
    + labs('Race or Ethnicity',
        y = 'Average "Risk of Violence" Decile Score',
        title = 'Average "Risk of Violence" Score by Race'
    )
)
plot.show()

We can see from the above plot that African-American defendants are especially likely to have higher average Risk of Violence decile scores, with low standard error, followed by Native American defendants (though their model coefficient was not statistically significant) and Arabic defendants (though there’s high standard error, indicating greater variance).

White, undeclared “Other”, and Hispanic defendants all have roughly the same average decile scores with low standard error. Asian defendants have the lowest average decile score, with moderate standard error.

Pairwise comparisons

We can more concretely identify whether there are statistically significant differences between pairs of races and ethnicities by completing a post-hoc test. pairs implements a Tukey HSD (“Honestly Significant Difference”) test, which is a post-hoc test to determine whether specific group means have significant differences from each other. We’ll filter the result to look at only the statistically significant differences (in this case, based on an \(\alpha = 0.05\) threshold).

pairwise = pairs(emm)

From the plot and the pairwise comparisons, we can see that African-American defendants were significantly more likely to receive higher Risk of Violence scores compared to all other races and ethnicities except for Native American defendants (which makes sense - we saw that the Native American confidence interval overlaps with the African-American score estimate in the plot). Additionally, Native American defendants were also significantly more likely to receive higher scores than all races and ethnicities apart from Arabic and African-American defendants.
